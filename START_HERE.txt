CANTEA - START HERE

1. Extract the ZIP completely into a new folder. Do not run inside the ZIP.
2. Close any old Cantea server windows.
3. Double-click START_CANTEA.bat. The browser opens automatically.
   Python 3.10+ is required; dependencies install on first start.
   Leave the server window open. No account details need typing there.
4. Click Owner Login at the top of the website.
5. If you do not know the owner password: close the server window,
   double-click OWNER_ACCOUNT.bat, and fill in the browser form.
   Use the existing owner email to reset it, or a new email to create an owner.
6. Sign in. The Kitchen Dashboard opens. Select Inventory.
   Choose an item > Receive / prepare portions > quantity > reason > Save.
7. Menu management lets you add/edit prices, images, availability and items.
8. Click your name > Change password to change a signed-in account password.

12 additional menu items are added automatically without changing existing stock.
New items start at zero: enter the actual prepared quantities in Inventory.

Online payments use Razorpay. Expand Online payments in the owner dashboard
for configuration. Cash works without gateway credentials.
This ZIP includes a website build; Node is only needed to rebuild source changes.
